BookHub — 安裝 / Installation
==================================
Tool
1.back-end : Python- flask
2.font-end : html,css
3.Data base : neon.com
4.Web Hosting : Render 
==================================

Installation
Install a necessary module

>> pip install flask "psycopg[binary]" python-dotenv pillow gunicorn

(note that:
flask	- creat Font-Backend and API
psycopg[binary] - connect Neon PostgreSQL
python-dotenv	- Read DATABASE_URLN and SECRET_KEY from .env
pillow - Seller Upload picture
gunicorn	- run Flask on Hosting like Render
werkzeug	Hash Password - 處理照片 Upload)

==================================
Run 

>> py run.py
 
 * Running on http://127.0.0.1:5000

(ctrl + click to url)

Stop

(ctrl + C)
